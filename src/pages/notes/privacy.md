## Your apps, independently

There is no suite account to create. Android's contacts, SMS and call-log providers are separate from the apps' own settings, saved items and organisation. Each app can be used independently.

Optional calling portraits use a compatibility and access contract between No Contact and No Call. Without a compatible installation or access, ordinary photos or initials remain available.

## Choosing access

- **Contacts:** No Contact uses this for the address book. Editing requires write access. In the other apps, it supports names and photos.
- **Default SMS role:** An eligible No Message build needs this and the relevant SMS permissions for provider-backed messaging. Carrier charges still apply.
- **Default Phone role:** An eligible No Call build needs this for its live call interface. Device and carrier capabilities affect controls.
- **Notifications:** Support alerts and reminders. Android notification settings remain in control.
- **Overlay access:** Optional, for supported floating islands outside the app.
- **Precise timing:** Some testing builds can request this for eligible reminders or schedules. It does not guarantee exact delivery.

A permission declaration, a default-app role and a special-access setting are different things. Review the explanation in the build you install.

## Local does not mean every file is encrypted

SMS is not end-to-end encrypted. Ordinary drafts and portable exports are not claimed to be app-encrypted. Manual exports are explicit and remain in the location you choose. Android's automatic backup and device transfer are disabled for app-owned private data in the current configuration.

Android account sync, carrier services, speech recognition, selected document providers and external apps can transfer data through their own services. Opening a link or using voice typing hands work to the handler you choose.

## This website

This local portfolio has no analytics, advertising, contact form or visitor account. Fonts and showcase media are served with the site. Videos wait for you to play them. External GitHub links take you to GitHub and its own privacy practices.
